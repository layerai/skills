# Layer Skills

Claude Skills for [Layer](https://layer.ai) — the AI-powered platform for game asset creation.

## What's included

- **[SKILL.md](SKILL.md)** — Teaches Claude when and how to use Layer's MCP tools for generating images, videos, 3D models, and audio

## Setup

This skill is designed to work alongside the [Layer MCP server](https://mcp.layer.ai). Connect the MCP server in your Claude client, then add this skill for the best experience.
